Stop Letting Spreadsheets Silently Destroy Your CSVs

Traditional spreadsheets guess data types the moment you open a file—destroying database keys, postal codes, dates, and phone numbers before you even press save. NanoCell treats CSV for what it is: structured verbatim text.

Core Architecture

What NanoCell Does Best

Instant O(1) Large File View

Inspect multi-gigabyte CSV dumps in milliseconds before spinning up Pandas, PySpark, or DuckDB. Samples header, intervals, and footer in a background Web Worker with safe View-Only lock.

100% Client-Side Privacy

Sensitive financial records, healthcare exports, and customer PII never leave your machine. Zero backend servers, zero telemetry, verifiable open-source code, and 100% offline capable.

Verbatim Text Accuracy

Every cell is handled as pure text. Leading zeros, + signs, and exact string literals stay intact. Multi-line clipboard paste maps cleanly without broken wizard dialogs.

RFC 4180 Compliance

Built on a strict RFC 4180 state-machine parser with auto-detected encodings (UTF-8, UTF-16, Latin-1) and delimiters (,, ;, TAB, |). Optionally enforces strict delimiter-safe saves.

Import-Ready in One Click

Turn messy vendor exports into clean database tables instantly. Fix dirty headers, locale numbers, and dates individually—or run your own multi-step cleanup macro in a single keystroke.

Install Anywhere

Locked corporate laptop where .exe and .dmg installers are blocked by IT? Install NanoCell as a standalone desktop PWA in one click with native OS file associations.

Philosophy

Simple, Reliable, and Universal
—By Design—

CSV has endured for decades because of three core values: simple, reliable, and universal. To this day, it remains the undisputed common interface for data tools. Above all, it guarantees your data stays readable forever without proprietary software or vendor lock-in.

Designed by and for data practitioners, NanoCell CSV brings those same values to your everyday workflow—a lightweight, dependable editor that stays out of your way and aims to be the go-to CSV tool for software engineers and data experts worldwide.

Shortcuts: Ctrl+K or Ctrl+P

Mode: Automatic on file open
Find & Bulk Replace

Search cells with live match counters and case sensitivity, or bulk-replace all occurrences across the sheet in one undoable step.

Shortcuts: Ctrl+F / Ctrl+Shift+F
JSON, Markdown & TSV Export

Export the full sheet or copy your active selection to the clipboard as pretty-printed JSON objects, GitHub Markdown tables, or TSV.

Extracts 40+ currency symbols and codes, formats numbers to 2 decimals, and splits ISO-4217 codes (USD, EUR, CHF) into a new column.

Validation Pane: Ctrl+Shift+P
Matrix Transposition

Pivots selected rows into columns and columns into rows. Ideal for re-orienting horizontal metric summaries for SQL ingestion.

Shortcut: Ctrl+Shift+T
Locale & Accounting Numbers

Duplicate Row Detector

Null & Error Cleaner

Clears placeholder tokens and broken spreadsheet formula errors (NULL, N/A, #N/A, NaN, None, #REF!, #VALUE!) to empty cells.
