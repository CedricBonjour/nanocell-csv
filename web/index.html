FAQ & Guides

Frequently Asked Questions

Common questions about verbatim CSV editing, large-file previews, and data cleanup workflows.

How do I open and edit a CSV file without losing leading zeros, + signs, or date formats?

NanoCell CSV treats every cell as 100% verbatim text by default. Postal codes like 02138, international phone numbers like +41 79 123 45 67, ISO dates like 2026-03-04, and 64-bit IDs are never auto-converted or truncated on open or save.

How can I preview a multi-gigabyte CSV file without freezing my computer?

NanoCell uses O(1) interval sampling in a background Web Worker to preview 5 GB+ CSV and TSV files in milliseconds, displaying the header, evenly spaced sample chunks, and the footer without loading the entire file into RAM.

Is NanoCell CSV private and does it work offline?

Yes. NanoCell runs 100% locally in your browser or as an installable offline Desktop PWA with zero server uploads, zero telemetry, and no network connection required after loading.

How do I install NanoCell on a corporate laptop without admin rights?

Open NanoCell in Chrome, Edge, or Brave and click Install in the top navigation bar. It installs as a standalone desktop application with native OS file associations for .csv and .tsv files—no .exe or .dmg administrator permissions needed.

What delimiters and character encodings are supported?

NanoCell automatically detects comma (,), semicolon (;), TAB, and pipe (|) delimiters alongside UTF-8, UTF-16LE/BE, Shift-JIS, GB18030, and Windows-1251/1252 encodings when opening a file.
